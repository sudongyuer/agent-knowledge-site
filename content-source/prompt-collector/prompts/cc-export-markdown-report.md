## 解决什么问题
分析、调研、方案讨论完，想留一份能读能存的文档时用，接在别的 prompt 后面当“收尾”。
> 大白话：mermaid = 用文字写出流程图/时序图的格式，很多 Markdown 阅读器能直接画出来。

## Prompt
原文（陈成第 3 条，英文，保留原拼写）：
```text
save to ~/Downloads/ in a seperate markdown in zh with mermaid if need
```
中文大意：保存到 ~/Downloads/，单独一个中文 Markdown 文件，需要的话配 mermaid 图。路径换成你习惯的文件夹即可。
