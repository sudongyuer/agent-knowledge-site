## 解决什么问题
防止 agent 闷头重复造轮子：先搜现成的库、方案、skill，再决定要不要自己写。

## Prompt
原文（评论区，@Ryanhan717，评论区点赞最高的回复之一，14 赞）：
```text
先去全网搜索相关内容 先去github搜索相关skill
```

通用版（本库整理，非原话）：
```text
动手之前，先全网搜索相关内容，再去 GitHub 搜有没有现成的库或 skill。把找到的候选列出来（链接、维护是否活跃、许可证），说明用现成的还是自己写，理由是什么，等我确认。
```

## 已知坑 & 评论区改进
